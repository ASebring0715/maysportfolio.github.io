CIS 296 - Quartly Sales Application

Developed a multi-controller ASP.NET Core MVC application to manage employees and their quarterly sales data using Entity Framework and a relational database.

The application follows the MVC design pattern, with separate controllers handling different responsibilities, including employee management and sales tracking. Dependency injection is used to access the database context, enabling efficient data operations and maintainable code structure.

The system supports full CRUD functionality, allowing users to create and view employees and sales records. Sales data can be filtered dynamically by employee, demonstrating the use of LINQ queries for conditional data retrieval. Data is passed between controllers and views using ViewData and ViewBag to support dropdown selections and filtering features.

Form submissions are secured using model validation and anti-forgery tokens, ensuring safe data entry. The application also includes relational data handling, such as assigning managers to employees and linking sales records to specific employees.

Key Features:
  • Multi-controller architecture (Home, Employee, SalesData)
  • Dependency injection for database access
  • Database context with DbSet configuration
  • Seed data for employees and sales records
  • Self-referenceing relationships (employee-manager hierarchy)
  • One-to-many relationship between employees and sales data
  • Dynamic filtering of sales data using LINQ
  • Full create and view functionality for employees and sales records
  • Custom validation methods for enforcing business rules
  • Secure form handling with anti-forgery tokens
