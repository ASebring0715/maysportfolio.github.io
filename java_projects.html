CIS 225 – Banking App


Developed a client-side banking web application that allows users to securely log in and view account information through integration with a backend REST API.

The application features a fully functional authentication system using modern JavaScript, including asynchronous API communication with fetch and async/await. User credentials are securely sent to the server, and upon successful login, a token-based authentication system is implemented by storing a session token in localStorage.

To protect sensitive data, the account dashboard verifies authentication tokens before granting access and uses Bearer token authorization in HTTP headers to securely retrieve account information. The application dynamically loads and displays user-specific data, such as account balance, through DOM manipulation.

Additional features include client-side routing and navigation, real-time error handling for failed login attempts or invalid sessions, and logout functionality that clears session data and redirects users appropriately. HTML5 form validation is used to ensure proper input, and event-driven programming techniques handle user interactions efficiently.

This project demonstrates key concepts in web development, including API integration, authentication and session management, secure data handling, and dynamic front-end development.

Key Features:
  • Secure login system with token-based authentication
  • Protected account page with authorization checks
  • Dynamic data retrieval and rendering
  • Error handling and user feedback
  • Logout and session management
  • Responsive and structured front-end design
